## Chapter 5: The Toolkit, and What It Really Costs

When I started building with AI, I expected the hardest part to be the technology. It wasn't. The hardest part was believing that tools this powerful could cost so little.

Many books and videos about AI promise a business "for free". That is not quite true, and I want this book to be honest. So in this chapter I will show you every tool I use, what each one does in plain words, and exactly what I pay for it.

### The four tools behind all four projects

Everything in this book was built with just four main tools.

**1. Claude, my AI partner.** Claude is the AI assistant made by Anthropic. I pay for the **Claude Pro** plan, which costs **$20 a month**. It gives me the chat assistant I use every day for planning, writing and problem-solving, and it includes **Claude Code**, the AI agent that actually builds things. Claude Code can read my project files, write code, run it, test it, and fix its own mistakes while I watch and guide it. If one tool in this book is essential, it is this one.

**2. GitHub, the filing cabinet.** GitHub stores all my project files online, keeps a history of every change, and can run small jobs automatically on a schedule. My blog engine runs there three times a week, and the blog itself is hosted there for free with a feature called GitHub Pages. For everything I do, GitHub costs me **nothing**.

**3. Cloudflare, the free server.** Cloudflare runs my Telegram booking app. Normally, an app needs a server, a computer that is always switched on, which you rent every month and must maintain. Cloudflare Workers runs small apps like mine on its own network instead, and its free plan is more than enough for a small business. Cost: **nothing**.

**4. A domain name, my address on the internet.** A domain is the name people type to find you, such as *homepicksunder30.com*. It is the only part of my setup with a yearly bill. Cost: **[DOMAIN $/YEAR] per year**.

### The free helpers

Around those four tools, I use a handful of free services. None of them asked for my credit card.

- **Telegram:** the app where my customers book deliveries and my team receives the orders
- **GoatCounter:** a simple, privacy-friendly visitor counter for the blog
- **Pinterest, TikTok and Facebook:** where I share content and video ads
- **Amazon Associates:** the affiliate program behind the blog, free to join
- **Amazon KDP (Kindle Direct Publishing):** where this book is published, free to use; Amazon takes its share only when a copy sells

### One cost that is easy to miss

There is one more cost, and it surprised me at first.

My blog engine does not use the Claude Pro chat. It talks to Claude automatically through the **Claude API**, a separate service for software, which is paid for by use rather than by month. You add credit, and each request uses a little of it. According to my project notes, one complete post pack, with an article, captions, video scripts and a compliance check, costs roughly **$0.10 to $0.30**. At three packs a week, that comes to only a few dollars a month. [⭐ Replace with your real API spending.]

The lesson: **a subscription and an API are not the same thing.** If you build something that runs by itself, check how it pays for its AI.

### What I don't pay for, yet

It is just as important to know what you *don't* need at the start:

- **No developers or agencies.** The AI builds; I direct and check.
- **No rented servers.** Free plans handle small traffic easily.
- **No paid design or video software.** The video ads are built from simple web pages.
- **No paid advertising.** Everything so far has grown without ads.

### When the costs will grow

Free plans have limits, and that is fair. If my projects succeed, some costs will rise:

- **More AI use:** a busier blog or more books means more API requests
- **Bigger Cloudflare or GitHub plans:** only if traffic grows far beyond a small business
- **Paid tools for growth:** design tools, advertising or email marketing, *after* something proves it can earn

My rule is simple: **pay for growth only after the free version has proved itself.**

### Before you spend anything

If you want to follow this book, here is all you need to begin:

1. A computer with a web browser and an internet connection
2. A Claude Pro plan ($20 a month), and you can cancel at any time
3. Free accounts on GitHub and Cloudflare
4. A domain name, but only when you have something worth showing to the world

That's it. In the next chapter, I will show you the most important skill of all, and it costs nothing: **how to talk to AI so it builds what you actually need.**
