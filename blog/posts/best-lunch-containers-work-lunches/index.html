Only if the manufacturer says so, so check the listing and the symbols on the container base before heating. Stainless steel, like the salad kit, never goes in the microwave.

Is a 20L lunch bag too big for one person?

Not if you pack a drink, a main and a snack. A slightly big bag closes easily, while a slightly small one means something stays home.

Do I need both the containers and the bento box?
